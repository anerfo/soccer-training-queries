WhatsApp Passkey-Kopplung

Dieses Werkzeug koppelt dein WhatsApp-Konto einmalig über einen Passkey. Es läuft lokal bzw. im Heimnetz – der Passkey verlässt dein Gerät nicht.

  1. Chrome mit der geladenen wa-passkey-connector-Erweiterung öffnen (siehe Anleitung).
  2. Diese Seite im selben Browser öffnen.
  3. „Passkey-Kopplung starten“ drücken und den Passkey (Windows Hello, Touch ID, Sicherheitsschlüssel …) bestätigen.
  4. Falls WhatsApp es verlangt: den angezeigten Code am Handy bestätigen.
Erweiterung wird gesucht …
Status wird geladen …

Nach erfolgreicher Kopplung den Worker mit Ctrl+C beenden und die neue Session-DB an den Daemon übergeben.
